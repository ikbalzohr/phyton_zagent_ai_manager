# Data Manager

This package is intentionally separate from the ArcMap Python 2.7 bridge.

Current functions:
- index local SHP/raster/MXD/LYR/GDB sources;
- discover exported SASPlanet rasters;
- generic HTTP downloader for public datasets.

Provider-specific government/OSM/DEM downloaders should be added as separate providers after the authoritative source and licensing rules are agreed.
