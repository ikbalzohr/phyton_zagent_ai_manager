# Map Profile Rules

Naming follows the user's established MXD convention:

`PETA A4 <PROJECT NAME> - <PROFILE>.mxd`

The suffix after ` - ` is authoritative for the profile name.

Examples already registered:
- Template Profile Administrasi
- Template Profile Kontur
- Template Profile Geologi
- Template Profile Pemantauan Lingkungan
- Template Profile Sampel

Additional profiles can be added later as JSON registry records and then enriched from live MXD inspection without changing the core architecture.
